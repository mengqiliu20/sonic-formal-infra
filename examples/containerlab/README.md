# Containerlab examples

Runnable [containerlab](https://containerlab.dev/) examples for exploring routing behavior.
These examples show model contributors how to translate abstract test operations
into concrete network configuration changes.

- [BGP-LS](bgp-ls/README.md): deploy an IS-IS/BGP-LS network and observe prefix,
  metric, attribute, and link updates.

To add a lab, include its topology, router configurations, and a README with
setup, observation, and cleanup instructions.
